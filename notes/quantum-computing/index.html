Qubits

A quantum bit (or qubit) is the basic unit of information in quantum computing. Unlike classical bits that are exclusively 0 or 1, a qubit exists in a superposition of both states. However, upon measurement, the qubit collapses to a classical bit value.

Mathematically, a qubit state is represented as:

∣ψ⟩=α∣0⟩+β∣1⟩|\psi\rangle = \alpha|0\rangle + \beta|1\rangle∣ψ⟩=α∣0⟩+β∣1⟩

where α,β∈C\alpha, \beta \in \mathbb{C}α,β∈C are complex amplitudes satisfying ∣α∣2+∣β∣2=1|\alpha|^2 + |\beta|^2 = 1∣α∣2+∣β∣2=1.

The states ∣0⟩|0\rangle∣0⟩ and ∣1⟩|1\rangle∣1⟩ form an orthonormal basis:

∣0⟩=(10),∣1⟩=(01)|0\rangle = \begin{pmatrix} 1 \\ 0 \end{pmatrix}, \quad |1\rangle = \begin{pmatrix} 0 \\ 1 \end{pmatrix}∣0⟩=(10​),∣1⟩=(01​)

Systems and States

A quantum system SSS may be in one of ddd different states, represented as ∣0⟩,∣1⟩,…,∣d−1⟩|0\rangle, |1\rangle, \ldots, |d-1\rangle∣0⟩,∣1⟩,…,∣d−1⟩.

  • Mathematically: ∣0⟩|0\rangle∣0⟩ is a column vector [1,0,…]T[1, 0, \ldots]^T[1,0,…]T, and so on
  • Transformations: A system may undergo a transformation RRR denoted as R∣x⟩R|x\rangleR∣x⟩
    • Mathematically, RRR is a matrix
    • Composition: UR∣x⟩UR|x\rangleUR∣x⟩ means apply RRR first, then UUU
  • Reversibility: In quantum computing, all transformations RRR must be reversible, i.e., R−1R^{-1}R−1 must exist such that RR−1=IRR^{-1} = IRR−1=I

Composite Systems

Composite systems are formed from two or more individual systems. If systems S1S_1S1​ and S2S_2S2​ combine, the composite system is denoted S1⊗S2S_1 \otimes S_2S1​⊗S2​.

The state of the composite system is:

∣x1⟩⊗∣x2⟩|x_1\rangle \otimes |x_2\rangle∣x1​⟩⊗∣x2​⟩

This is often abbreviated as:

∣x1⟩⊗∣x2⟩=∣x1⟩∣x2⟩=∣x1,x2⟩=∣x1x2⟩|x_1\rangle \otimes |x_2\rangle = |x_1\rangle|x_2\rangle = |x_1, x_2\rangle = |x_1 x_2\rangle∣x1​⟩⊗∣x2​⟩=∣x1​⟩∣x2​⟩=∣x1​,x2​⟩=∣x1​x2​⟩

Transformations on composite systems: If RRR is applied to S1S_1S1​ and UUU is applied to S2S_2S2​, we write:

(R⊗U)(∣x1⟩⊗∣x2⟩)=R∣x1⟩⊗U∣x2⟩(R \otimes U)(|x_1\rangle \otimes |x_2\rangle) = R|x_1\rangle \otimes U|x_2\rangle(R⊗U)(∣x1​⟩⊗∣x2​⟩)=R∣x1​⟩⊗U∣x2​⟩

Some transformations cannot be written as independent transformations on each subsystem. These are entangling operations, such as CNOT.

Measurement

When a qubit in state ∣ψ⟩=α∣0⟩+β∣1⟩|\psi\rangle = \alpha|0\rangle + \beta|1\rangle∣ψ⟩=α∣0⟩+β∣1⟩ is measured in the computational basis:

  • Outcome ∣0⟩|0\rangle∣0⟩ occurs with probability ∣α∣2|\alpha|^2∣α∣2
  • Outcome ∣1⟩|1\rangle∣1⟩ occurs with probability ∣β∣2|\beta|^2∣β∣2
  • The state collapses to the measured outcome

Bell States

The four Bell states are maximally entangled two-qubit states:

∣Φ+⟩=12(∣00⟩+∣11⟩)∣Φ−⟩=12(∣00⟩−∣11⟩)∣Ψ+⟩=12(∣01⟩+∣10⟩)∣Ψ−⟩=12(∣01⟩−∣10⟩)\begin{align*} |\Phi^+\rangle &= \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle) \\ |\Phi^-\rangle &= \frac{1}{\sqrt{2}}(|00\rangle - |11\rangle) \\ |\Psi^+\rangle &= \frac{1}{\sqrt{2}}(|01\rangle + |10\rangle) \\ |\Psi^-\rangle &= \frac{1}{\sqrt{2}}(|01\rangle - |10\rangle) \end{align*}∣Φ+⟩∣Φ−⟩∣Ψ+⟩∣Ψ−⟩​=2​1​(∣00⟩+∣11⟩)=2​1​(∣00⟩−∣11⟩)=2​1​(∣01⟩+∣10⟩)=2​1​(∣01⟩−∣10⟩)​

Creating Bell States

Starting with ∣Φ1⟩=12(∣00⟩+∣11⟩)|\Phi_1\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)∣Φ1​⟩=2​1​(∣00⟩+∣11⟩), we can create all four Bell states using two classical bits b1,b2b_1, b_2b1​,b2​:

Apply operations based on b1b_1b1​ and b2b_2b2​:

  • b2=0b_2 = 0b2​=0: No operation on second qubit
  • b2=1b_2 = 1b2​=1: Apply XXX (bit flip) on second qubit
  • b1=0b_1 = 0b1​=0: No operation on first qubit
  • b1=1b_1 = 1b1​=1: Apply ZZZ (phase flip) on first qubit

Result: ∣Φ4⟩=∣b1b2⟩|\Phi_4\rangle = |b_1b_2\rangle∣Φ4​⟩=∣b1​b2​⟩ (encodes both bits into Bell state)

Key insight: CNOT on entangled states helps recover information about which Bell state we started with by measuring the second qubit.

Information Theory in Quantum Computing

Amount of Information

An nnn-qubit system is in superposition of 2n2^n2n states:

∣ψ⟩=∑x∈{0,1}nαx∣x⟩|\psi\rangle = \sum_{x \in \{0,1\}^n} \alpha_x|x\rangle∣ψ⟩=x∈{0,1}n∑​αx​∣x⟩

This appears to perform 2n2^n2n calculations in parallel, but measurement collapses to a single outcome.

Holevo’s Theorem

Setup:

  • Alice has an mmm-bit string mxm_xmx​
  • She encodes it into an nnn-qubit quantum state
  • Bob performs unitaries + measurement to recover mxm_xmx​

Theorem: mx=mx′m_x = m_x'mx​=mx′​ with high probability only if n≥mn \geq mn≥m.

In other words, you need at least as many qubits as classical bits to reliably transmit information.

Superdense Coding

If Alice and Bob share pre-shared entanglement, then n=m/2n = m/2n=m/2 qubits is sufficient!

Protocol: Alice can transmit 2 classical bits using 1 qubit + 1 pre-shared EPR pair.

Circuit:

Starting with EPR pair ∣Φ1⟩=12(∣00⟩+∣11⟩)|\Phi_1\rangle = \frac{1}{\sqrt{2}}(|00\rangle + |11\rangle)∣Φ1​⟩=2​1​(∣00⟩+∣11⟩):

  1. Alice applies gates based on (b1,b2)(b_1, b_2)(b1​,b2​):

    • b2=1b_2 = 1b2​=1: Apply CNOTb2→0\text{CNOT}_{b_2\to0}CNOTb2​→0​
    • b1=1b_1 = 1b1​=1: Apply CZb1→0CZ_{b_1\to0}CZb1​→0​

  2. Result: State becomes one of the four Bell states encoding b1b2b_1b_2b1​b2​

  3. Bob applies CNOT + H to distinguish which Bell state, measuring ∣b1b2⟩|b_1b_2\rangle∣b1​b2​⟩

Result: 2 bits transmitted with 1 qubit!
